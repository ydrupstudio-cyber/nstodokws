# 앵커 규격과 좌표

기본 자세 14종 × 5단계 = 70개. 성체 수정본을 기준으로 그림은 그대로 두고 보이지 않는 마커와 표정만 추가했습니다. 귀 없는 뇌·척추는 9개, 동물은 11개 마커입니다. `data-point`는 성장 배율 적용 전 리그 좌표, `data-scale`은 기준 아이템에 적용하는 배율입니다.

모션 결합은 `data-parent`, `data-local-point`, `data-local-scale`을 사용합니다. 아이템을 그 부모 그룹의 자식으로 붙여 부모의 매 프레임 변형을 자연스럽게 상속합니다. 전역 좌표와 로컬 좌표를 중복 적용하지 마세요. `back`은 `pet` 안에서 몸 뒤에 삽입하고 `body`의 현재 변형을 복사합니다. 새 코드가 이를 처리합니다.

기존 walk/rest SVG는 교체하지 않습니다. `motion-anchors.json`에 별도 계산한 140개 포즈의 좌표를 제공합니다. `equip(svg,items,motionAnchors[source])`로 넣으면 파일 수정 없이 같은 아이템을 붙일 수 있습니다. 기존 파일에는 새 표정이 없으므로 표정 어댑터가 open/smile로 자동 대체합니다.
